# ProjectBoard 交互预览

当前 UI 框架参考 Kaneo 官方应用演示：窄侧栏、顶部路径与页签、完整窗口工作区。知识库采用“树—内容—属性与关联”布局。

打开 `index.html` 即可预览，无外部字体、CDN 或第三方脚本依赖。推荐使用固定本地地址，以保持浏览器数据存储位置一致：

```powershell
node D:\Github\ProjectBoard\preview\serve.cjs
```

然后在外部浏览器访问 http://127.0.0.1:4173 。当前服务已启动并保留。服务器仅提供预览首页和健康检查，不暴露项目文件。

默认直接进入工作空间；退出后可用 `admin / admin123` 登录。如果自行设置了预览密码，则使用设置的密码。

## 可操作范围

| 区域 | 已提供的预览操作 |
| --- | --- |
| 项目 | 新建、编辑简介和目录、切换、归档与恢复、概览 |
| 我的工作 | 跨项目任务列表、进行中/到期/逾期数量、关键词与优先级筛选 |
| 任务 | 新建、编辑、状态、日期、优先级、标签、列表/看板、拖动和按钮排序、自定义状态与迁移 |
| 任务详情 | 评论流、回复/编辑/删除恢复、附件选择/拖放/粘贴与下载、独立 URL 与刷新、按需添加/清空字段、五级优先级、三种日期、进度、颜色、提醒/重复配置、任务与知识关联、清单、记录、删除恢复 |
| 知识树 | 根节点和子节点、内容编辑、自动保存、精确点分地址定位、重命名、移动、排序、置顶、子树复制 |
| 知识关系 | 稳定 ID 引用、节点双向关联、从知识创建任务、内容与标签历史快照及恢复 |
| 标签 | 单节点标签、多标签 AND/OR 筛选、关键词叠加、批量添加/移除、改名合并、移除标签、按标签批量删除节点 |
| 回收站 | 完整子树删除影响清单、恢复位置选择、任务恢复、永久删除 |
| 搜索 | 项目、任务、节点内容、地址与标签统一检索 |
| 设置 | 明暗主题、预览登录/密码流程、完整 JSON 备份导出和导入、任务 CSV 导出、示例重置 |

标签不会自动继承到子节点。批量修改标签只作用于选中的节点；删除节点会包含子节点，操作前列出最终影响范围。

## 推荐体验路径

1. 在地址栏输入 `技术.开发.启动命令` 并回车。
2. 编辑节点内容，新增子节点并添加标签。
3. 从知识创建任务，添加检查项和工作记录。
4. 将任务记录写入节点，再移动节点，检查任务引用仍然有效。
5. 在项目标签页切换任务/知识类型、多选标签、全选结果，体验批量标记和删除影响清单。
6. 在回收站恢复子树，在设置中导出或恢复备份。

## 预览边界

数据保存在当前浏览器的 localStorage；换浏览器、换地址、清理网站数据会影响可见数据。备份不包含管理员密码。当前是单文件交互原型，正式版仍需实现 Go 服务、SQLite、真实会话安全、安装升级、HTTP/HTTPS 配置和性能验收。

预览以普通文本管理知识内容；节点并不对应磁盘文档。修改历史演示内容与标签恢复，完整结构变更审计、服务器冲突合并以及正式版独立深链接仍由后续产品实现。

# 项目标签与 MCP 补充

项目顶部现为“概览 / 任务 / 知识库 / 标签 / MCP”。标签页仅管理当前项目，任务和知识节点共用词表，支持类型筛选、AND / OR 匹配、批量添加/移除标签和删除内容。改名、合并、删除标签覆盖当前项目任务与节点（包括回收站），不会改变其他项目的同名标签。

MCP 页提供连接设计及六个浏览器内工具演示。添加/移除标签会更新预览数据；当前没有真实 HTTP 或 stdio MCP 服务，不能直接连接外部客户端。完整方案见 [MCP 设计](../docs/mcp-design.md)。
# 独立任务页面与字段

新建任务只需标题；进入独立页面后点击“添加字段”，选择并填写所需属性。字段可清空，已有任务的值保留。任务链接支持直接打开、刷新和浏览器前进后退。字段目录与空值规则见 [任务页面与字段](../docs/task-fields.md)。提醒和重复周期仅保存预览配置，尚不执行定时触发。
# 评论与时间线

任务页以评论为主体，支持文字、附件、回复、编辑和删除恢复。选择/拖放/粘贴文件后发表评论，图片内嵌，其他文件可下载。预览每条最多 8 个附件，单文件 512 KB、总量 1.5 MB；正式版使用本地附件目录。

任务面板现有“看板 / 列表 / 时间线”。时间线支持按月查看开始/结束区间及截止标记，无日期任务列在“未安排”。详见 [设计与范围](../docs/comments-and-timeline.md)。
# 初始状态

新任务默认状态为“创建”，去掉“待处理”和未设置状态列；其余字段仍按需设置。旧任务的空状态和“待处理”会自动迁移到“创建”，包括回收站记录。当前默认流程为创建、进行中、已完成、已取消。
# 固定任务详细

任务标题下固定显示“任务详细”，默认阅读状态，点击“编辑”后修改文字和图片/文件附件，保存或取消后返回阅读状态。评论流显示在它下方。两者附件分别归属，共用预览容量；旧描述直接保留为任务详细。添加属性统一使用“属性”标题旁的“＋”，不再显示重复的“添加字段”按钮。
