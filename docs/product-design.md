# ProjectBoard 1.0 产品与实现

当前方案以 2026-09-05 冻结预览为界面基准。正式应用使用相同导航、任务页、知识树和标签操作，数据接入本地服务。

## 产品范围

单管理员、本地工作空间。项目包含任务、知识和独立标签。任务提供看板、列表和月度时间线；我的工作支持项目筛选。任务详细固定显示在评论上方、默认阅读，属性通过右侧“＋”设置。新任务初始状态为“创建”。

知识节点同时具有内容和子节点，点分地址在项目内唯一；稳定 ID 用于关联。节点支持移动、重命名、置顶、关联、版本历史和子树删除恢复。标签共用于项目内的任务与知识，支持 AND/OR 筛选、批量增删、改名合并及回收站内容同步管理。

图片、文本和 Markdown 附件支持预览；Markdown 可切换排版与源码。提醒保存在本地服务，浏览器提醒中心展示；用户可选择开启桌面通知。重复任务完成后生成一次后继任务。

## 运行结构

```text
浏览器（内嵌 HTML / CSS / JavaScript）
            ↓ 同源 HTTP
Go 服务 ── 管理员会话、API、项目 MCP
            ↓ 统一验证、修订号和提交入口
SQLite 工作空间快照 + 内部附件目录
```

保留原生前端以沿用已确认交互，最终浏览器端无需第三方 JavaScript 运行库。Go 1.26、modernc SQLite 驱动、官方 MCP Go SDK、Goldmark Markdown 渲染器随单个程序构建。

SQLite 的 workspace 表保存带版本和修订号的实体快照；独立表保存管理员、会话、令牌、附件元数据和提醒。该方案让 Web 与 MCP 的跨实体变更使用同一验证入口，整次操作提交或回滚。每次写入校验全局 revision；后台同步先查询轻量修订号，仅在变更时拉取数据。前端编辑草稿与阅读状态分别处理。

这是对最初 React 与细分关系表建议的实现选择：首版保留已验收界面并降低构建复杂度。10,000 任务 / 2,000 节点性能实测见验收报告；将来可保持 API 契约并拆分内部存储。

## 安装与认证

默认监听 127.0.0.1:7331，数据位于 Windows LOCALAPPDATA/ProjectBoard。运行时创建应用目录、打开浏览器，并通过一次性初始化令牌设置管理员密码。支持数据目录、监听地址、Host 和 HTTPS 证书参数。

密码使用 bcrypt；HttpOnly、SameSite=Strict 会话 Cookie，HTTPS 下启用 Secure。写入校验 CSRF、Origin 和 Host。改密清理旧会话，本机 CLI 支持隐藏输入重设密码。操作系统文件锁保证数据目录单实例使用。重复启动识别本应用，其他服务占用端口时报告可执行的处理方式。

## 保存、附件与恢复

知识内容按纯文本安全呈现。自动保存成功后显示“已保存”；冲突保留草稿并提供导出和载入最新内容。任务字段和评论等待服务端确认后显示成功。

附件使用随机 ID 文件和 SQLite 元数据，保留 SHA-256 摘要；文件名只用于显示和下载。每个文件 20 MB、每个区域 8 个、工作空间总附件 256 MB。无引用附件在暂存 24 小时后清理，回收站引用继续保留。

ZIP 备份包含事务一致的逻辑数据快照、附件字节和校验清单。恢复验证结构、文件路径、大小和摘要，先保存当前备份，再以一次 SQLite 提交替换工作空间。导入时附件使用新 ID，失败不会覆盖当前附件。管理员及接入凭据保留在当前安装中。

数据库格式为版本 1，工作空间 JSON 兼容 schema 2。旧程序数据使用独立数据库文件；高版本数据库被拒绝打开。更新前通过设置导出备份。

## MCP

同进程 Streamable HTTP；stdio 是连接运行中服务的适配入口。每个令牌限定一个项目，37 个工具覆盖项目、任务、评论、附件、知识、标签与批量删除。写入使用 expected_revision；删除子树通过带完整影响范围的短期计划确认。详见 MCP 文档。

## 验收

自动化覆盖认证、项目隔离、字段清空、任务编号、树约束、附件预览、备份恢复、事务冲突、提醒重复、HTTP / stdio MCP、单实例与独立启动。浏览器验收记录和实际测量见 release-test-report.md。
