# 界面文案约定

- 面向使用者描述操作，按钮使用“动作 + 对象”。
- 页面保留标题、字段、内容与操作；实现原理和设计说明放入项目文档。
- 空状态给出下一步，例如“写下第一条评论”“点击编辑，补充任务详细”。
- 校验提示给出可执行的修正方式，例如“请选择 512 KB 以内的文件”。
- 成功提示直接报告结果，例如“任务详细已保存”。
- 删除与恢复确认写明操作对象、影响范围和数据去向。
- 容量以简短数值展示；演示功能使用“浏览器演示”“配置预览”等准确标签。
- 项目名称、任务内容、评论和知识内容由用户管理。
