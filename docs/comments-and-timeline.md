# 评论、附件与时间线

## 任务页面

任务详细固定在评论上方，默认阅读；点击编辑后填写文字和添加附件，保存或取消返回阅读。评论流始终显示，支持文字、附件、回复、编辑、删除恢复和写入知识节点。Ctrl/Cmd+Enter 发表评论，确认保存后清空草稿。

## 附件

任务详细与评论均支持文件选择、拖放和粘贴。文件由本地应用内部管理；文件名不是存储路径。单文件上限 20 MB，每个区域最多 8 个文件，工作空间附件总量 256 MB。

- 图片：PNG、JPEG、GIF、WebP 缩略图，点击放大，支持缩放与适应窗口。
- 文本：UTF-8 / UTF-16 原样阅读；TXT、日志、代码、JSON 等文本文件均可预览。
- Markdown：GFM 标题、列表、表格、代码块、引用；切换排版预览和源码。
- 文本预览展示前 1 MB，完整内容通过下载查看。
- SVG / HTML 按文本或下载处理。Markdown 原始 HTML 和危险链接不作为页面执行，远程图片不自动加载。

预览窗口有独立下载入口。评论删除后附件一起隐藏，恢复时保留；永久删除后的无引用文件经过 24 小时暂存期后清理。ZIP 备份包含实际字节和 SHA-256 校验。前端文字草稿保存在当前浏览器会话，待提交文件保留在内存；服务器暂存上传文件以便完成保存。

## 时间线

看板、列表和时间线共用筛选与排序。时间线按月显示，支持前后月份和返回本月；左列固定任务名称，日期区域横向滚动。开始和结束都有值时显示区间；开始、结束、截止各有标记。只有部分日期时只显示实际字段；日期为空的任务进入待安排区。点击名称、区间或标记进入独立任务页。

当前时间线用于查看和打开任务；日期通过任务属性编辑。
