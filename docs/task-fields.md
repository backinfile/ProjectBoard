# 任务页面与字段

## 页面

任务详细默认阅读，点击“编辑”进入编辑状态，保存或取消后返回阅读。添加属性只保留右侧“属性”标题旁的“＋”入口。

任务从看板、列表、标签结果、搜索与知识关联统一进入独立页面。地址为 `#/projects/<project-id>/tasks/<task-id>`，支持复制链接、直接访问、刷新与浏览器前进后退。链接引用本地服务中的稳定 ID，多个浏览器共享同一数据。

页面沿用 Kaneo 工作区框架：顶部项目导航与任务编号，主体从上到下为固定任务详细（文字与附件）、评论流，清单和关联可展开，右侧显示已设置的属性。手机上属性区位于内容下方。编辑标题、设置字段或添加内容使用同一套操作，不再把任务放在覆盖式抽屉中。

## 默认值

创建仅需标题。ID、项目归属、编号、排序与创建时间是系统元数据。初始状态固定为“创建”，其他业务字段（包括优先级）默认为空；空集合表示没有添加相应内容。任务详细固定显示，其余可选字段手动添加并保存值后才显示；取消不生成默认值。清空字段后恢复隐藏。

已有任务保持填写过的值，不批量清除历史数据。所有任务使用相同字段定义和编辑规则。从知识节点创建任务时，关联该节点是用户明确选择的上下文，其他字段仍不预填。

## 字段目录

参考 [Vikunja 任务说明](https://vikunja.io/help/tasks/)及[日期与提醒](https://vikunja.io/help/dates-and-reminders/)，保留适合本地单人项目的字段。负责人、订阅者和权限字段继续省略；附件现通过评论上传，见 [评论、附件与时间线](comments-and-timeline.md)。

| 字段 | 值与约束 | 空值 |
| --- | --- | --- |
| 任务详细 | 固定字段，多行纯文本与附件 | 编辑区始终显示在评论上方 |
| 状态 | 默认“创建”，另有进行中、已完成、已取消及自定义状态 | 重置回“创建”；无“待处理”或空状态列 |
| 优先级 | 低、中、高、紧急、立即处理 | 没有优先级，不自动设为中 |
| 开始 / 截止 / 结束日期 | 独立日期，结束不可早于开始 | 不显示日期属性 |
| 进度 | 0–100 的整数百分比 | null；0% 是已设置值 |
| 提醒时间 | 本地绝对日期时间 | 不提醒 |
| 重复周期 | 每天 / 每周 / 每月 | 不重复 |
| 颜色 | #RRGGBB，预览中显示为色点 | 使用普通任务外观 |
| 标签 | 当前项目词表，可多个 | 空列表 |
| 关联知识 | 同项目稳定节点 ID | 空列表 |
| 关联任务 | 同项目其他任务，相关 / 阻塞此任务 / 子任务 | 空列表 |
| 检查清单 | 文本与完成状态 | 空列表 |
| 评论 | 文字、回复、附件与时间；始终显示输入区 | 空列表 |

提醒按运行服务的本地时区执行，保存在提醒中心；浏览器打开时可显示通知，桌面通知由用户主动开启。每天、每周、每月重复任务在标记完成时生成一次后继任务，日期按周期推进；每月月底自动取下月有效日期。后继任务保留任务详细、标签、知识关联及附件，重置状态、进度、评论、清单完成情况，使用新编号。进度仍是独立手动值。

## 统一呈现与管理

字段目录是详情、列表和 CSV 的共同来源。看板只显示有值的优先级、截止日期、进度、标签与关联摘要；列表显示当前结果中有人使用的属性列，单项空值显示横线。状态筛选从“创建”开始；优先级筛选可以查找未设置项。优先级排序按立即处理到低，未设置项排最后。

清空标量属性直接保存；清空描述、清单或整组关联会先确认影响；评论逐条删除并可恢复。清空关联不会删除关联对象。任务删除仍进入回收站，恢复保留全部字段。备份导入验证新增字段，兼容此前 schema 2 的任务；字段缺失按未设置处理。

MCP 与 Web 使用相同字段模型。create_task 默认状态为“创建”；update_task 的 fields 中省略字段表示保持，显式 null（标量）或空数组（集合）表示清空；状态的 null 表示重置为“创建”。Web 工作空间快照沿用 schema 2 的空字符串与空集合表示，服务端统一校验。MCP 已实现真实读写。
