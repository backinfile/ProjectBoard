## 使用边界

- 桌面提醒由用户在浏览器中开启；浏览器关闭期间由服务记录提醒，重新打开后查看。
- 附件每个 20 MB、每个区域 8 个、工作空间总量 256 MB；文本预览前 1 MB，可下载完整内容。
- Markdown 使用安全渲染，远程图片通过文本占位；图片附件在预览中缩放。
- 数据库是 SQLite 内的版本化实体快照；整次变更使用全局修订号，编辑冲突由草稿导出和载入最新内容处理。
- 包含回收站的完整备份保留附件，管理员和 MCP 凭据留在当前安装。
- 本轮重点验收 Windows；HTTPS 通过测试服务器和安全 Cookie/来源校验测试，实际证书由部署者提供。
