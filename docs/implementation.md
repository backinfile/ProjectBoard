## 实现决策

- 沿用冻结界面，原生 HTML/CSS/JavaScript 接入同源 Go 服务。
- 单文件程序内嵌前端，SQLite 持久化实体快照；应用内部文件目录存放附件。
- Web 与 MCP 共用领域验证和带修订号提交，项目令牌严格隔离。
- 任务详细阅读态、评论主体、按需属性与标签项目边界保持一致。
- 完成重复任务时生成一次后继任务；本地提醒中心与用户选择的桌面提醒。
- ZIP 逻辑快照与附件摘要备份，恢复前备份和原子替换。
- 默认端口 7331，独立验收目录与用户工作空间分离。
